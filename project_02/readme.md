This file contains the full PCB design for my Pomodoro Study Timer built around the PocketBeagle.
Included are my Eagle schematic, board layout, custom library, mechanical drawing, Gerbers, and BOM.
To create the board board, I used a seven-segnment display (HT16K33), two pushbuttons, a potentiometer, a buzzer, and seven LEDs.
Gerbers in the docs/ folder were used to generate MacroFab quotes for 1/10/100/1000 units.
See docs/ for the schematic PDF, mechanical layout, and top/bottom copper previews.
Designed by Paige Rennie for EDES 301 (Fall 2025).
